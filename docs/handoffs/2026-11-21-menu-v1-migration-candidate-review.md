2. Exact modifier pricing: migrate modifier price rules from \`size_key\` to \`product_variant_id\`, resolving any existing rows before dropping the old key; abort if any row cannot map.

7. Draft revision state, append-only audit, immutable compiled publication JSON snapshots, and atomic current-publication pointer.
8. New public tables owned by postgres, RLS enabled, no policies or app-role grants.
